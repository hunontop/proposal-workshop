## 레퍼런스 이미지는 각자 준비하세요

디자인 실습에서 레퍼런스 이미지 2장(디자인 언어 / 색 계열)을 함께 첨부합니다.
저작권 때문에 여기서 배포하지 않습니다 — 여러분 조직에서 잘 만든 자료 2장을 쓰시면 됩니다.

## 페이지 다시 만들기

```bash
python _build.py
```

`index.html`은 생성물입니다. 색은 강의 덱의 `skin.json`에서 읽어 오므로 덱과 톤이 자동으로 맞습니다.
자료를 추가할 때는 `files/`에 파일을 넣고 `_build.py`의 `SESSIONS`에 한 줄 추가하면 됩니다.
