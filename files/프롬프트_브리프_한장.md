# 실습 프롬프트 — 브리프 한 장 만들기 (덱 43장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> **작업 폴더는 hun_proposal을 설치한 그 폴더**입니다. 재료는 **여기서 만듭니다** — 앞 폴더에서 옮겨 오지 않습니다.
> 42장에서 고른 **그 공고 하나**의 첨부와 **프로필 카드**, 둘이면 됩니다. 첨부는 **42장에서 이미 받았습니다.**

---

## 1. 재료 확인

이 폴더에 둘이 있어야 합니다 — **42장에서 받은 첨부**와 **프로필 카드**.

```
지금 작업 폴더에 어떤 파일이 있는지 보여줘
```

### 카드가 아직 없으면

실습 자료에서 **복사**해 붙여넣고 파일로 저장시킵니다.

```
아래 내용을 프로필카드.md 로 이 폴더에 저장해줘.

(여기에 프로필 카드를 붙여넣습니다)
```

## 2. 브리프 만들기

```
이 폴더의 공고 첨부와 프로필 카드를 근거로 요구사항 브리프를 요구사항.md 로 정리해줘.

담을 것:
- 무엇을 만드는 문서인가 (제출처 · 마감 · 분량)
- 우리가 누구인가 (프로필 카드에서)
- 공고가 요구하는 것 (배점 항목 · 제출물)
- 강조할 것 / 피할 것

두 파일에 없는 값은 지어내지 말고 "(확인 필요)"라고 적어줘.
매출·실적·재무 숫자는 특히 그렇게 해줘.
```

## 3. 사람이 읽고 고칩니다

**여기는 프롬프트가 없습니다.** 나온 문서를 읽고, 틀린 곳은 **말로** 고치면 됩니다 — *"3번 항목을 이렇게 바꿔줘"* 처럼요.

> **비운 칸이 비운 채로 남았는지**만 꼭 보세요. 지어냈으면 그 자리에서 돌려보냅니다.

## 4. 공정에 넣습니다

브리프가 마음에 들면 **이제 궤도에 올립니다.**

```
이 요구사항.md 로 제안 공정을 시작해줘.
여정 이름은 알아볼 수 있게 지어줘 — 공고 이름과 우리 아이템이 들어가게.
```

⚠ **이름을 안 주면 파일 이름을 그대로 씁니다** — 여정이 `요구사항`이라는 이름으로 생깁니다. 나중에 여정이 여러 개가 되면 어느 게 어느 건지 알 수 없습니다.

### 이름이 이상하게 생겼다면

**폴더 이름만 바꾸면 안 됩니다.** 여정 이름이 안쪽 기록에도 적혀 있어서 어긋납니다. **다시 시작하는 게 맞습니다** — 브리프가 이미 있으니 금방입니다.

```
여정 이름이 마음에 안 들어. 알아볼 수 있는 이름으로 다시 시작해줘.
그리고 먼저 만들어진 여정은 정리해줘.
```

> 정리할 때 **승인 창이 뜹니다.** 32장에서 배운 **멈출 신호 셋** 중 하나(**삭제**)입니다 — 무엇을 지우는지 읽고 승인하세요.

여정 폴더가 생기고 단계가 한글로 깔립니다(`01_공고찾기` … `14_마무리`).

그다음부터는 이 두 마디면 됩니다.

### 지금 어디까지 됐나

```
지금 어디까지 됐어?
```

### 다음으로

```
다음 단계로 진행해줘.
```

> **막히면 문서를 뒤지지 말고 「지금 어디까지 됐어?」를 물으세요.** 이 과정 내내 쓰는 한마디입니다.
