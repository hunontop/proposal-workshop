# 실습 프롬프트 — 브리프 한 장 만들기 (덱 42장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> **재료는 전부 내 폴더 안에 있습니다** — 23장에서 내려받은 **공고 첨부**, 그리고 **프로필 카드**.
> 인터넷이 안 돼도 됩니다. 에이전트가 이 파일들을 합쳐 요구사항 문서로 정리하고, **사람이 읽고 고칩니다.**

---

## 1. 재료 확인

작업 폴더에 두 가지가 있는지 먼저 봅니다.

```
지금 작업 폴더에 어떤 파일이 있는지 보여줘
```

> ⚠ **23장에서 첨부를 안 챙겼으면 여기서 막힙니다.** 그때 지우지 말라고 한 이유가 이것입니다.

## 2. 브리프 만들기

```
이 폴더의 공고 첨부와 프로필 카드를 근거로 요구사항 브리프를 요구사항.md 로 정리해줘.

담을 것:
- 무엇을 만드는 문서인가 (제출처 · 마감 · 분량)
- 우리가 누구인가 (프로필 카드에서)
- 공고가 요구하는 것 (배점 항목 · 제출물)
- 강조할 것 / 피할 것

두 파일에 없는 값은 지어내지 말고 "(확인 필요)"라고 적어줘.
매출·실적·재무 숫자는 특히 그렇게 해줘.
```

## 3. 사람이 읽고 고칩니다

```
3번 항목에 이 내용을 넣어줘 — (직접 쓴 문장)
```

---

## 볼 것

- **비운 칸이 비운 채로 남았습니까.** 지어냈으면 그 자리에서 돌려보냅니다
- 이 문서가 다음 단계로 **그대로 들어갑니다** — 여기서 대충 두면 뒤가 전부 흔들립니다

> 산출물은 **요구사항 브리프 1부**입니다. 실물 예시는 함께 배포한 「브리프 예시 — 말벗ON」에 있습니다.
