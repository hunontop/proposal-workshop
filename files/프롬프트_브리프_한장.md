# 실습 프롬프트 — 브리프 한 장 만들기 (덱 43장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> **작업 폴더는 hun_proposal을 설치한 그 폴더**입니다. 재료는 **여기서 만듭니다** — 앞 폴더에서 옮겨 오지 않습니다.
> 42장에서 고른 **그 공고 하나**의 첨부와 **프로필 카드**, 둘이면 됩니다.

---

## 1. 재료를 이 폴더에 만듭니다

**고른 공고의 첨부**를 여기서 받습니다. 42장에서 고른 그 한 건입니다.

```
방금 고른 공고의 첨부파일(신청서 서식·배점표)을 이 폴더에 받아줘.
```

> 앞에서 받아 둔 첨부가 이미 있으면 그걸 쓰면 됩니다. **없어도 여기서 다시 받으면 그만입니다** — 고른 건 한 건뿐이라 금방입니다.

**프로필 카드**는 실습 자료에서 **복사**해 붙여넣고 파일로 저장시킵니다.

```
아래 내용을 프로필카드.md 로 이 폴더에 저장해줘.

(여기에 프로필 카드를 붙여넣습니다)
```

## 2. 브리프 만들기

```
이 폴더의 공고 첨부와 프로필 카드를 근거로 요구사항 브리프를 요구사항.md 로 정리해줘.

담을 것:
- 무엇을 만드는 문서인가 (제출처 · 마감 · 분량)
- 우리가 누구인가 (프로필 카드에서)
- 공고가 요구하는 것 (배점 항목 · 제출물)
- 강조할 것 / 피할 것

두 파일에 없는 값은 지어내지 말고 "(확인 필요)"라고 적어줘.
매출·실적·재무 숫자는 특히 그렇게 해줘.
```

## 3. 사람이 읽고 고칩니다

```
3번 항목에 이 내용을 넣어줘 — (직접 쓴 문장)
```
