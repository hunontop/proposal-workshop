# 실습 프롬프트 — 이미지를 자동으로 (덱 52장 · 선택)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> **연결하지 않아도 됩니다.** 52장에서 본 **길 B(수동)**로 끝까지 갈 수 있습니다 — 프롬프트를 복사해 ChatGPT나 Gemini에 붙이면 그만입니다.
> 이 문서는 **길 A(자동)**를 써 보고 싶을 때만 필요합니다. 공정이 이미지 모델에 직접 보냅니다.

---

## 먼저 알아 둘 것

**수동으로 이미 몇 장을 만들었어도 괜찮습니다.** 자동으로 갈아타도 **이미 있는 장은 건너뜁니다** — 처음부터 다시 만들지 않습니다.

## 1. 연결시키기

작업 폴더에서 에이전트에게 시킵니다. **설치와 로그인을 한 번에** 맡깁니다.

```
이미지를 자동으로 만들 수 있게 Codex CLI를 연결하고 싶어.
docs/codex_연결.md 를 읽고 그대로 설치해줘.
로그인은 브라우저 창이 뜨면 내가 직접 할게 — 그 단계에서 멈추고 알려줘.
```

⚠ **로그인은 사람이 합니다.** 계정 창이 뜨면 거기서부터는 직접 하세요. 에이전트에게 계정 정보를 주지 않습니다.

## 2. 연결됐는지 확인시키기

```
Codex CLI가 연결됐는지 확인해줘.
이 공정이 그걸 인식하는지도 같이 봐줘.
```

## 3. 이어서 만들기 — 남은 장만

```
아직 이미지가 없는 장만 자동으로 생산해줘.
이미 만들어 둔 장은 그대로 두고.
```

> 수동으로 만든 장은 **그대로 남습니다.** 자동은 **빈 자리만** 채웁니다 — 두 길의 결과물이 한 덱에서 섞여도 됩니다. 파이프라인이 보는 것은 *"정확한 크기의 이미지가 제자리에 있는가"*뿐입니다.

---

## 무료로 되나요

**됩니다.** 무료 ChatGPT 계정으로 로그인해도 동작합니다.

다만 **무료는 한도가 가장 낮고**, 이미지 생성은 일반 작업보다 **한도를 3~5배 빨리** 씁니다. 크레딧을 살 수 없어 한도에 걸리면 리셋(약 5시간)을 기다려야 합니다.

> **한두 장 해 보는 용도**로 생각하세요. 스무 장을 자동으로 돌리려면 유료 플랜이 필요합니다.
> 그래서 **이 과정의 기본은 길 B**입니다 — 회사에 자동 연결이 없어도 이 공정을 쓸 수 있다는 게 52장의 요점이었습니다.

## 막히면

**길 B로 돌아가면 됩니다.** 연결은 선택이고, 두 길의 결과물은 같은 계약을 지킵니다.

```
자동 연결이 잘 안 돼. 수동으로 만드는 방법으로 안내해줘.
```
