## 붙여 넣기 전에 (걸림 지점 4가지)

1. **정확한 px는 웹 생성기에서 안 나온다.** 프롬프트는 `exact 1792 x 784`를 요구하지만 ChatGPT/Gemini는 근사치를 낸다 — **정상이다**. 공정의 `--adopt`가 비율을 존중해 잘라 맞춘다(시연 1차: 1897×829 → 1792×784, 손실 거의 0).
2. **저장 경로 지시는 뺐다.** 원본 프롬프트 끝에는 `imagedeck/slides/...` 저장 경로가 붙어 있는데 그건 자동 루트(CLI)용이다. 여러분은 **파일 이름을 장 번호로 시작**해서 받은 그대로 저장하면 된다. (예: `06_내가만든장표.png`)
3. **다운로드한 파일을 run 폴더에 손으로 넣지 않는다.** 반드시 `--adopt`를 거친다. 손으로 넣으면 다음 재조립 때 사라진다 — 산출물은 공정이 만든다.
4. **레퍼런스는 첨부하지 않아도 된다.** 색 계약이 프롬프트 문장 안에 있기 때문이다(실측 확인). 여러 장을 시리즈로 만들 때만 첨부를 권한다.
