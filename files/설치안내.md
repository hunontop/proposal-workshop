## ③ 제안 자동화 공정 — 수업 중 (S4)

```
git clone https://github.com/hunontop/hun_proposal.git
```

받은 폴더에서:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python dashboard/test_smoke.py
```

마지막 줄이 **`OK`** 로 끝나면 성공입니다.

- 설치는 **1분이 안 걸립니다**(실측: 받기 1초 + 설치 20초 + 확인 22초).
- `skipped` 항목이 있어도 정상입니다 — 브라우저 도구를 안 깔았을 때 건너뛰는 검사입니다.
- 대시보드 첫 화면이 **비어 있는 것도 정상**입니다. 공고는 ②로 직접 모읍니다.
- **막히면 화면의 오류 메시지를 그대로 에이전트에게 붙여넣으세요.** 그게 이 과정에서 계속 쓰는 방법입니다.

## 왜 직접 설치하나요

남이 깔아 준 도구는 남의 것입니다. **설치·경로·오류 대응 구간**이 대부분의 AI 교육에서 통째로 비어 있고, 첫날 이탈이 거기서 납니다. 이 과정은 그 구간을 정면으로 지나갑니다 — 그래서 수업이 끝나면 **내 PC에서 도는 도구 2종**이 남습니다.
