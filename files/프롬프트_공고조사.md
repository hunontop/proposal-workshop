# 실습 프롬프트 — 공고 조사 (덱 21·23장)

> 아래 문장을 그대로 복사해서 붙여넣으세요.
> 앞선 실습(18장 「프롬프트 4요소 카드」)에서 잘 묻는 법을 봤다면, 여기서는 **어디까지 닿는지**를 봅니다.
> 자기 화면이 강사 화면과 달라도 괜찮습니다. **된 것과 안 된 것을 적어 두는 것**이 이 실습의 목적입니다.

## 1. 공고 찾기

```
기업마당에서 예비창업자를 위한 공고를 찾아줘
```

찾아 준 공고 중 하나를 골라 **링크를 주고** 자격·마감·개요를 정리해 달라고 이어서 시킵니다.
여기까지는 대체로 됩니다 — **검색도 되고 본문도 읽습니다.**

## 2. 첨부 열기

```
공고에 붙은 첨부파일(신청서 서식·배점표)을 열어서 배점 항목을 정리해줘
```

## 3. 적어 둘 것

- 검색은 됐는가
- 본문(자격·마감·개요)은 읽었는가
- **첨부는 받아졌는가** · 배점표는 나왔는가

멈추는 자리가 있습니다. **고장이 아닙니다** — 다음 장에서 그 자리가 어디인지 정확히 가릅니다.

# 23장 — 사람이 가져다줍니다

담장 앞에서 멈춘 그 일을, 이번엔 **사람이 재료를 가져다주고** 시킵니다.

## 4. 손으로 가져오기

1. 브라우저로 **공고 상세 페이지**를 엽니다.
2. **본문을 복사**합니다.
3. **첨부를 내려받습니다**(hwpx · pdf).

> ⛔ **내려받은 첨부를 지우지 마세요.** 뒤(42장 브리프)에서 **그 파일이 그대로 재료**가 됩니다.

## 5. 분석시키기

복사한 본문을 붙여넣고 첨부를 올린 다음, 아래를 보냅니다.

```
첨부한 공고 본문과 파일을 프로필 카드 관점으로 분석해줘.

- 신청자격이 되는가 (되는 것 / 안 되는 것 / 확인이 필요한 것)
- 배점 항목은 무엇인가
- 무엇을 제출해야 하는가
- 마감은 언제인가
- 카드에 없어서 못 채우는 칸은 무엇인가

카드에 없는 값은 지어내지 말고 "(카드에 없음)"이라고 적어줘.
```

## 6. 볼 것

- **사람이 가져다주니 배점표까지 읽습니다** — 능력이 아니라 접근이 문제였습니다
- **빈칸이 빈칸으로 남아 있습니까.** 매출·실적 같은 것을 지어냈다면 돌려보냅니다
