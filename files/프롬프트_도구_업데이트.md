# 실습 프롬프트 — 도구 업데이트 확인 (부록)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> 과정이 끝난 뒤에도 도구는 고쳐집니다. **지금 내 사본이 언제 것인지 확인하고, 필요하면 갱신하는** 한마디입니다.
> 명령을 외우지 않습니다 — 늘 그랬듯 **에이전트에게 시킵니다.**

---

## 1. 내 사본이 언제 것인지

도구를 설치한 폴더에서 에이전트를 엽니다.

```
이 도구가 어느 시점 사본인지 알려줘.
그리고 더 새 버전이 나와 있는지도 확인해줘.
```

`VERSION` 파일에 **버전 · 빌드 날짜 · 만들어진 시점**이 적혀 있습니다. 도구가 그걸 읽고 사람 말로 답합니다.

## 2. 갱신시키기

```
새 버전이 있으면 최신으로 갱신해줘.
내가 넣어 둔 파일은 지우지 말고.
```

> **내가 만든 것은 남습니다** — 여정 폴더(run), 내가 넣은 지식 카드(`pull-knowledge/`), 회사 프로필. 갱신은 **도구 쪽만** 바꿉니다.

## 3. 갱신 뒤 확인

```
갱신 잘 됐는지 확인해줘.
```

설치 직후에 했던 그 한마디와 같습니다. **버전이 올라갔는지**와 **점검이 통과하는지** 둘을 봅니다.

---

## 언제 하면 되나

**정기적으로 할 일이 아닙니다.** 이 셋 중 하나일 때만 하면 됩니다.

- 오래 안 쓰다가 **다시 꺼낼 때**
- 뭔가 **안 되는데 이유를 모를 때** — 이미 고쳐졌을 수 있습니다
- 새 기능을 **쓰고 싶을 때**

## 안 될 때

갱신이 막히면 **지금 사본을 그대로 쓰면 됩니다.** 과정에서 한 일은 전부 지금 사본으로 됩니다 — 갱신은 필수가 아닙니다.

```
갱신하다가 이 에러가 났어. 무슨 뜻이고 어떻게 하면 되는지 알려주고, 고쳐줘.
```

> 설치 때와 같은 한마디입니다. **막혔을 때 되묻는 법**은 도구가 바뀌어도 그대로입니다 — 그게 이 과정에서 가져가는 것입니다.
