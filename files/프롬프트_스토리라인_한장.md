# 실습 프롬프트 — 스토리라인에서 한 장 (덱 47장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> 도식으로 넘어가기 전에 **방향을 굳히고, 그림으로 그릴 한 장을 꺼냅니다.**
> napkin은 **글을 넣으면 도식 후보를 주는** 도구입니다 — 넣을 글이 있어야 시작됩니다.

---

## 1. 남은 관문이 있으면 마저

```
지금 어디까지 됐어?
```

고칠 것은 **말로** 고치고 체크합니다. 방향이 굳을 때까지입니다.

## 2. 스토리라인 꺼내기

`05_내용동결`에 있습니다. **장별로 무슨 말을 할지** 정해진 문서입니다.

```
스토리라인이 어디에 있는지 알려주고, 내용을 보여줘.
```

## 3. 그림으로 그릴 한 장 고르기

```
그중에서 그림으로 그려 보면 좋을 것 같은 장 하나를 골라서,
그 장의 내용만 따로 보여줘.
```

**그 내용을 복사해 두세요.** 다음 실습에서 napkin에 그대로 붙여넣습니다.

> ⚠ **여기서 안 챙기면 다음 실습이 빈손으로 시작됩니다.**

---

## 손에 남는 것

- **동결된 스토리라인** — 수집부터 방향까지 **한 사이클을 손으로 돌아 나온 것**
- 그중 **골라 둔 한 장** → 다음은 도식입니다

> ★ **여러분 손으로 실행하는 것은 여기까지입니다.** 이후 디자인과 이미지 생산은 함께 보면서 **판단**합니다.
