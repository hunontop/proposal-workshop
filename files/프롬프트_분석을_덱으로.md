# 실습 프롬프트 — 분석을 슬라이드덱으로 (덱 26장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> 앞(23장)에서 만든 **공고 분석**을 그대로 재료로 씁니다. 발표자료 스킬을 켜고 같은 대화에서 이어가세요.
> **이 실습은 두 번 합니다.** 지시 없이 한 번, 지시를 넣고 한 번 — 그 차이를 보는 것이 목적입니다.

---

## A. 빈칸 지시 없이

```
방금 분석으로 검토 보고용 슬라이드 5~6장 만들어줘.
공고 개요, 적합성, 요건, 일정, 준비물, 그리고 빈칸.
```

## B. 카드를 주고, 빈칸을 지시하고

```
같은 내용을 다시 만들어줘. 이번엔 첨부한 프로필 카드만 근거로 써줘.

카드에 없는 값은 채우지 말고 "(카드에 없음)"이라고 그대로 적어줘.
매출·실적·재무처럼 카드에 없는 숫자를 추정해서 넣지 마.
```

---

## 두 결과를 나란히 놓고 볼 것

1. **A에서 지어낸 칸이 있습니까** — 체크리스트를 전부 충족한 것처럼 쓰여 있지 않은지
2. **B에서 빈칸이 살아남았습니까**
3. 어느 쪽이 **제출할 수 있는 문서**인지

> 지어낸 값은 편해 보이지만 **탈락 사유**가 됩니다. 비어 있는 칸은 채우면 되지만,
> 지어낸 칸은 어디가 지어낸 것인지 나중에 알 수 없습니다.
