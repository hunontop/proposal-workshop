# 실습 프롬프트 — 관문까지 돌리기 (덱 45·46장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> 공정을 시작했으면 이제 **방향이 굳을 때까지** 돌립니다. 여기까지가 **여러분 손으로 실행하는 마지막 구간**입니다.
> 끝나면 **스토리라인**이 나옵니다 — 그게 다음 편(도식)에서 napkin에 넣을 재료입니다.

---

## 1. 다음 단계로 계속

```
다음 단계로 진행해줘.
```

**한 번에 끝까지 가지 않습니다.** 멈출 곳까지만 가고 섭니다. 멈추면 다시 같은 말을 하면 됩니다.

```
지금 어디까지 됐어?
```

> 여정 폴더에 `01_공고찾기` → `02_착수판단` → `04_내용만들기` → `05_내용동결` … 순서로 자리가 채워집니다. **탐색기로 직접 열어 보세요.**

## 2. 관문에서 멈추면

**멈춘 것은 고장이 아닙니다.** 사람이 봐야 할 자리에 온 겁니다. 그 폴더의 **검토 체크**를 엽니다.

```
지금 뭘 확인해야 하는지 알려줘.
```

### 실패를 한 번 보고 갑니다

```
그냥 넘어가줘
```

**다음 명령이 실패합니다.** 부탁으로는 안 열립니다 — **체크가 되어야** 열립니다. 이게 관문입니다.

### 고치고 통과시키기

읽고, 고칠 것은 **말로** 고칩니다.

```
2번 항목이 사실과 달라. 이렇게 고쳐줘 — (직접 쓴 문장)
```

맞으면 사람이 체크합니다. **고치면 관문이 다시 섭니다.**

## 3. 방향이 굳으면 — 스토리라인 꺼내기

`05_내용동결`까지 오면 **스토리라인**이 나와 있습니다. 장별로 무슨 말을 할지 정해진 문서입니다.

```
스토리라인이 어디에 있는지 알려주고, 내용을 보여줘.
```

**그중 한 장을 골라 그대로 복사해 두세요.** 다음 편에서 **napkin에 붙여넣을 재료**입니다.

```
그중에서 그림으로 그려 보면 좋을 것 같은 장 하나를 골라서,
그 장의 내용만 따로 보여줘.
```

> ⚠ **여기서 안 챙기면 다음 편에서 붙여넣을 게 없습니다.** napkin은 **글을 넣으면 도식 후보를 주는** 도구라, 넣을 글이 있어야 시작됩니다.

---

## 손에 남는 것

- **동결된 스토리라인** — 수집부터 방향까지 **한 사이클을 손으로 돌아 나온 것**
- 그중 **골라 둔 한 장** → 다음 편 도식의 입력

> ★ **여러분 손으로 실행하는 것은 여기까지입니다.** 이후 디자인과 이미지 생산은 함께 보면서 **판단**합니다.
