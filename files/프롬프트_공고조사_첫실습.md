# 실습 프롬프트 — 공고 조사 (덱 21장)

> 아래 문장을 그대로 복사해서 붙여넣으세요.
> 앞선 실습(18장 「프롬프트 4요소 카드」)에서 잘 묻는 법을 봤다면, 여기서는 **어디까지 닿는지**를 봅니다.
> 자기 화면이 강사 화면과 달라도 괜찮습니다. **된 것과 안 된 것을 적어 두는 것**이 이 실습의 목적입니다.

## 1. 공고 찾기

```
기업마당에서 예비창업자를 위한 공고를 찾아줘
```

찾아 준 공고 중 하나를 골라 **링크를 주고** 자격·마감·개요를 정리해 달라고 이어서 시킵니다.
여기까지는 대체로 됩니다 — **검색도 되고 본문도 읽습니다.**

## 2. 첨부 열기

```
공고에 붙은 첨부파일(신청서 서식·배점표)을 열어서 배점 항목을 정리해줘
```

## 3. 적어 둘 것

- 검색은 됐는가
- 본문(자격·마감·개요)은 읽었는가
- **첨부는 받아졌는가** · 배점표는 나왔는가

멈추는 자리가 있습니다. **고장이 아닙니다** — 다음 장에서 그 자리가 어디인지 정확히 가릅니다.
