# 실습 프롬프트 — 설치와 첫 분류 (덱 34~36장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> **설치도 에이전트에게 시킵니다.** 여러분이 명령어를 치지 않습니다 —
> **주소를 주고 「사용할 수 있게 설치해줘」**라고 말하면 받는 것부터 확인까지 도구가 합니다.
> ⚠ 먼저 **작업 폴더를 정하고 그 폴더에서 에이전트를 엽니다**(31장에서 한 그대로).
> 아래는 **강의에서 하는 순서 그대로**입니다. 위에서부터 차례로 쓰세요.

---

## 설치 ① 공고 수집 스킬 (34장)

### 1. 설치시키기

```
https://github.com/hunontop/gongo-fetch

이 프로젝트를 사용할 수 있게 설치해줘.
```

### 2. 잘 됐는지 확인시키기

```
잘 설치됐는지 확인해줘.
```

**명령어를 외우지 않습니다.** 확인도 사람 말로 시키고, 도구가 사람 말로 답합니다.

### 3. 시운전 — 조건을 주고 **1건만** 받아 보기

```
기업마당에서 예비창업자가 지원할 수 있는 공고를 찾아줘.
그중 1건만 골라서 상세와 첨부파일을 이 폴더에 저장해줘.
```

⚠ **전부 받으라고 하지 마세요.** 수백 건이 걸려 한참 걸립니다. **여기서 볼 것은 양이 아니라 「되는가」**입니다 — 1건이면 충분합니다. 많이 모으는 것은 나중에 공정이 합니다.

**볼 것**: 파일이 폴더에 쌓이는 것. 그리고 **판단은 하지 않는다는 것** — 어느 공고가 좋은지는 말해 주지 않습니다. 고장이 아니라 설계입니다. 고르는 것은 42장에서 사람이 합니다.

## 기준은 우리 카드가 줍니다 (35장)

34장에서 받은 **그 한 건**을 **프로필 카드 기준으로** 판정해 봅니다. 카드를 채팅에 붙여넣고 아래를 보냅니다.

```
첨부한 프로필 카드를 기준으로 이 공고를 판정해줘.
A 지금 되는 것 / B 조건을 갖추면 되는 것 / C 아이템을 다시 봐야 하는 것 중 어디인지,
왜 그런지 근거를 달아서 알려줘.
카드에 없어서 판단할 수 없는 것은 "(카드에 없음)"이라고 적어줘.
```

> **여기서는 한 건입니다.** 여러 건을 모아 고르는 일은 **7편(42장)**에서 합니다 — 그때가 「선택」이 주제인 자리입니다.

### 볼 것

**판단 기준이 어디서 왔는지.** 스킬이 아니라 **우리 카드**입니다 — 카드가 다르면 분류도 달라집니다. 34장에서 도구는 **가르기만** 했습니다.

## 설치 ② hun_proposal (36장)

빈 폴더를 하나 만들고, 그 폴더에서 에이전트를 엽니다.

**이번에는 설치와 확인을 한 번에 시킵니다.**

```
https://github.com/hunontop/hun_proposal

이 프로젝트를 사용할 수 있게 설치하고, 설치됐는지 확인까지 해줘.
```

마지막에 초록색 `OK`가 보이면 끝난 것입니다.

> **이 폴더가 앞으로의 작업 폴더입니다.** 7편의 수집·선택·브리프가 전부 여기서 돕니다.
> 재료는 **그때 그 자리에서** 만듭니다 — 미리 옮겨 두지 않습니다.

## 막혔을 때 — 이게 진짜 실습입니다

**설치는 원래 막힙니다.** 32장에서 배운 그대로 하면 됩니다 — **에러를 해독하지 말고, 통째로 복사해서 돌려주세요.**

```
설치하다가 이 에러가 났어. 무슨 뜻이고 어떻게 하면 되는지 알려주고, 고쳐줘.
```

> 여기서 막히는 것이 정상입니다. 강사도 막힙니다. **막혔을 때 되묻는 이 한 줄이 이 편에서 가져갈 것**입니다.
