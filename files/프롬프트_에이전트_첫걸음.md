# 실습 프롬프트 — 에이전트 첫걸음 (덱 30·31·32장)

> **AI 기초부터 업무 자동화까지 · 실습 배포물.**
> 여기서부터는 채팅창이 아니라 **에이전트**입니다. 말로 시키면 **내 컴퓨터에 파일이 생깁니다.**
> 개념 설명은 함께 배포한 「경로 · 작업 폴더 · 터미널」과 「승인 판단 카드」에 있습니다. 이 문서는 **시킬 문장**만 담습니다.

---

## 첫 한마디로 파일 만들기 (30장)

빈 폴더를 하나 만들고, 그 폴더에서 에이전트를 엽니다.

```
여기에 안녕.txt 만들고 오늘 날짜 적어줘
```

> **화면에 글자가 뜬 것으로 넘어가지 마세요.** 탐색기(파인더)에서 **그 파일을 직접 찾아 여는 것**까지가 이 실습입니다.

---

## 여기가 어디인가 (31장)

내 이름으로 폴더를 하나 만들고, 그 폴더에서 에이전트를 엽니다.

### 지금 자리 묻기

```
지금 작업 폴더가 어디야?
```

### 일 시키기

```
회의 메모 3개 만들어서 날짜별로 정리해줘
```

탐색기로 결과를 확인합니다.

### 자리를 옮겨 보기

폴더를 **다른 곳으로 옮긴 뒤** 다시 열고, 같은 질문을 합니다.

```
지금 작업 폴더가 어디야?
아까 만든 회의 메모 찾아줘
```

> **못 찾는 것이 정상입니다.** 자리가 바뀌면 결과도 바뀝니다 — 이 실습의 전부가 그 한 가지입니다.

---

## 실패는 정상입니다 (32장)

### 일부러 실패시키기

```
없는파일.txt 열어줘
```

빨간 글씨가 뜹니다. **해독하지 마세요.**

### 에러를 그대로 돌려주기

에러 메시지를 **통째로 복사해서** 붙여넣고, 뒤에 한 줄만 붙입니다.

```
이 에러가 났어. 무슨 뜻이고 어떻게 하면 되는지 알려줘.
```

### 되돌리기

앞에서 만든 파일 하나를 지우게 한 뒤:

```
원래대로 돌려줘
```

> **승인 창이 뜨면 멈춥니다.** 멈출 신호 셋 — **삭제 · 전부/전체 · 설정 변경**.
> 자세한 것은 「승인 판단 카드」에 있습니다.
> ⚠ 되돌리기 연습은 **반드시 내 연습 폴더에서** 합니다.

---

## 손에 남는 것

- 말로 시켜서 만든 **파일 1개**
- 자리를 옮겼을 때 무슨 일이 생기는지 본 **기록**
- **실패 → 복구 1건**
