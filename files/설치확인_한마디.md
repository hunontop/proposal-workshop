# 설치 확인 한마디 — 복사해서 붙여 넣으세요

> **AI 기초부터 업무 자동화까지 · 실습 배포물.** 덱 36장 「시운전 · 물어보면 답합니다」에 씁니다.
> 설치가 끝났는지는 **에이전트에게 물어서** 확인합니다. 명령어를 외울 필요가 없습니다.

---

## 1. 잘 깔렸는지 확인

```
방금 설치한 도구가 잘 깔렸는지 확인해줘.
안 되는 게 있으면 무엇이 문제인지 쉬운 말로 알려줘.
```

## 2. 지금 어디까지 됐는지

```
지금 이 폴더에 뭐가 설치돼 있고, 다음에 뭘 하면 되는지 알려줘.
```

## 3. 막혔을 때 — 이게 제일 중요합니다

화면에 뜬 **빨간 글씨를 통째로 복사**해서 앞에 한 줄만 붙입니다.

```
이런 오류가 났어. 무슨 뜻이고 어떻게 하면 되는지 알려줘.

(여기에 오류 메시지를 그대로 붙여넣기)
```

> **고쳐 쓰지 말고 그대로 붙여넣으세요.** 요약하면 단서가 사라집니다.

---

## 무엇이 보이면 된 건가

에이전트가 **사람 말로** 답합니다. 초록 글씨나 `OK` 같은 표시를 직접 찾지 않아도 됩니다.

| 답이 이러면 | 뜻 |
|---|---|
| "정상적으로 설치돼 있습니다" + 확인한 항목 나열 | ✅ 됐습니다 |
| "○○가 없습니다" · "○○를 먼저 해야 합니다" | 그 한 줄이 곧 다음 할 일입니다. 그대로 시키세요 |
| 무슨 소린지 모르겠다는 식으로 되묻는다 | **작업 폴더가 다른 곳일 수 있습니다.** *"지금 작업 폴더가 어디야?"* 로 먼저 확인하세요 |

---

> 이 과정에서 **사람이 명령어를 치지 않습니다.** 받기·설치·확인 전부 말로 시킵니다.
> 막히면 순서가 있습니다 — **먼저 에이전트에게**, 그래도 안 되면 스크린샷과 상황 한 줄.
